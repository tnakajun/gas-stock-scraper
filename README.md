プロジェクト名:
AI・半導体市況の自動データ収集＆相関分析パイプライン（PoC）

■ 概要
世界のテクノロジートレンドを牽引する主要な半導体メーカー（NVIDIA, TSMC, Micron）および、メガクラウド・AIベンダー（Microsoft, Google, Amazon）の株価データをAPI経由で毎日自動取得し、Googleスプレッドシートに蓄積・可視化するデータパイプラインです。

■ 制作の背景と目的

課題: 日々変動するテクノロジー市場において、「半導体の需要（価格）」と「クラウド・AIベンダーの成長（株価）」の相関関係を分析するには、毎日手作業でデータを集計する手間がかかっていました。

目的: この課題を解決するため、外部APIを用いたデータ収集処理を完全自動化し、常に最新の市場トレンドを可視化できるダッシュボードの基盤（PoC）を構築しました。

■ 使用技術・ツール

Google Apps Script (GAS): 外部APIとの連携、毎日の自動実行（トリガー処理）、データ整形（JSONパース）

Google Spreadsheet: データの永続化（データベースとしての活用）、時系列グラフを用いたダッシュボードによる可視化

Yahoo Finance API: リアルタイムな金融データの取得（REST API）

■ システムの特徴・アピールポイント

完全自動化: GASの時間主導型トリガーにより、人手を一切介さずに24時間365日データが蓄積され続けます。

高い拡張性: 取得対象の銘柄（企業）を増やす際も、コード内の配列を1箇所変更するだけで、自動的にスプレッドシートの列が拡張される柔軟な設計にしています。

ビジネス視点の分析: 「作る」だけでなく、最終的にビジネスの意思決定（トレンド予測や相関分析）に使える形にデータを整えることを意識して設計しています。
