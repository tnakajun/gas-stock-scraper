# AI・半導体市況の自動データ収集＆相関分析パイプライン (PoC)

## ■ 概要
世界のテクノロジートレンドを牽引する主要な半導体メーカー（NVIDIA, TSMC, Micron）および、メガクラウド・AIベンダー（Microsoft, Google, Amazon）の収益データをAPI経由で毎日自動取得し、Googleスプレッドシートに一時・一元化するデータパイプラインです。

## ■ 制作の背景と目的
* **課題:** 日々変動するテクノロジー市場において、「半導体の需要（価格）」と「クラウド・AIベンダーの成長」の相関関係を分析するには、毎日手作業でデータを集計する手間がかかっていました。
* **目的:** この課題を解決するために、外部APIを用いたデータ収集処理を完全自動化し、常に最新の市場動向を予測できるダッシュボードの基盤(PoC)を構築しました。

## ■ 使用技術・ツール
* **Google Apps Script (GAS):** 外部APIとの連携、毎日の自動実行（トリガー処理）、データ整形（JSONパース）
* **Google Spreadsheet:** データの永続化（データベースとしての活用）、時系列グラフを用いたダッシュボードによるマネジメント
* **Yahoo Finance API:** 金融なリアルタイムデータの取得（REST API）

## ■ システムの特徴・アピールポイント
1. **完全自動化:** GASの時間主導型トリガーにより、人手を一切介さずに24時間365日データが継続されます。
2. **高い拡張性:** 取得対象の銘柄（企業）を増やす際にも、コード内の配列を1箇所変更するだけで、自動的にスプレッドシートの列が拡張される柔軟な設計にしています。
3. **ビジネス視点の分析:** 「作る」だけでなく、最終的にビジネスの意思決定（トレンド予測や相関分析）に使える形でデータを整えることを意識して設計しています。
